# Surface: site (public landing page)

Mode: Persuade. Static Astro site in `site/`, deployed to GitHub Pages (`conghai20.github.io/haryx`) and served at `haryx.wecoap.com` through a proxy.

Audience: developers who hold several of their own Claude subscriptions. Job: understand HaryX in one viewport, install it (macOS or Windows one-liner, or Releases). Proof: real product facts from README only; demo accounts are labelled illustrations. No users, testimonials, metrics or press exist; never invent them. Must carry the "use within Anthropic's terms" honesty and the not-affiliated notice.

Constraints: brand commitments in PRODUCT.md (mark, palette Midnight Navy / Electric Cyan / Soft White, Space Grotesk + Geist). Light and dark follow the system. On the web, Midnight Navy is the dark ground (the app's "navy is only the tile" rule is a native-app rule; owner pinned navy ground here). Reduce Motion honoured.

## Direction contract

THESIS: a gallery poster for a routing tool. One drawn X, one tide line, huge quiet space; refuses the SaaS hero (headline + screenshot + feature-card grid).

OWN-WORLD: midnight-navy ground (dark) or soft-white paper (light); one live cyan; the mark's two halves as the only illustration; tide staffs (flat bars, pace tick) as the only data graphic; Space Grotesk display, Geist text, Geist Mono for real commands only; hairline rules, no cards, no shadows, no gradients.

STORY: visitor sees two strokes draw the X, reads "Take control of your AI workflow.", watches a sample tide rise and the route switch accounts, reads what it does as captioned lines, reads the terms note, copies the install command.

FIRST VIEWPORT: wordmark top-left, GitHub/Releases top-right; giant mark (~45vh) drawn stroke-first then filled, offset right; headline bottom-left at display scale; a full-bleed tide line crossing under it; install command with macOS/Windows switch and Copy as the primary action, visible above the fold.

FORM: pinned. seed: none (pinned) — owner chose "Ink & tide: gallery-poster feel: huge whitespace, giant X mark drawn as two strokes animating in, tide-line motif from the app's 'Tide Table' design, Space Grotesk, navy/cyan/soft-white only."

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
